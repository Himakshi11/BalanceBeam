### ⚡ BalanceBeam | Expense Tracker

🚀 Developed a full-stack financial management web application using the **MERN stack** (MongoDB, Express.js, React.js, and Node.js) to help users maintain financial stability by efficiently **tracking income and expenses**.

📊 Enabled users to **visualize spending patterns** and generate **insightful financial reports** for better financial awareness and decision-making.

🔐 Implemented **secure JWT-based authentication**, along with a **responsive dashboard** and **interactive charts** to provide a clear and intuitive overview of financial activities.
